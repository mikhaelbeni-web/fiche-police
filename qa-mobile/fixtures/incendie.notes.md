- États calculés au 2026-11-08 : SSI bientôt (37 j), VMC bientôt (23 j), Désenfumage non conforme (réserves longues), Extincteurs en retard + trou de suivi 2023→2025, BAES conforme via intervention corrective, Électricité conforme « date à confirmer », Colonne sèche jamais, Plan d'évacuation / Télésurveillance sans échéance (documents seuls), Ascenseurs (nom très long, 60 mois), Hotte cuisine (18 mois, option hors liste) en retard.

## Risques mobile (360–430 px)
1. `pages/incendie.js:155-171` : barre d'outils à 7 contrôles (2 onglets, + Nouveau contrôle, Imprimer, Importer, Changer le code, Verrouiller) → 3-4 lignes de boutons de ~30 px (globals.css:370-372, `.inc-import` 713) avant tout contenu ; « Imprimer » inutile sur téléphone.
2. `pages/incendie.js:285` + `styles/globals.css:719` : puces `.inc-chip` (padding 3px 10px, 12px) ≈ 22 px de haut → cible tactile trop petite ; textes longs (« … en retard de 49 j (échéance 20/09/2026) »).
3. `pages/incendie.js:429` : `<label style={{ minWidth: 240 }}>` (pièce jointe) dans un formulaire imbriqué dans `.inc-detail` dans une cellule : largeur dispo ≈ 238 px à 360 px → débordement léger ; `min-width` n'est pas neutralisé par la règle mobile.
4. `pages/incendie.js:405` (DocLine) : références/noms sans espace (« SOC-2026-000312-DES-IDF-NORD-RAPPORT-COMPLET ») dans `.inc-doc` sans `overflow-wrap` → débordement de la carte.
5. `pages/incendie.js:618` : `<tfoot>` en mode carte (globals.css:787 `.inc-fact tfoot td {display:block}`) : « Total », HT et TTC s'empilent sans libellé `data-label` → ligne de total illisible.
6. `pages/incendie.js:304-317` : la ligne entière est cliquable (`tr onClick`) et le ▼ (`.inc-open`, sans data-label) se retrouve seul sur une ligne de la carte ; pas d'affordance claire « toucher pour déplier ».
7. `pages/incendie.js:393` / `:614` : boutons ✕ de suppression isolés en fin de carte, sans libellé (risque de tap accidentel, code requis heureusement).
8. `pages/incendie.js:573` : `.recap-total .n` à 34px (globals.css:200) pour « 22 xxx,xx € » — tient, mais pousse le titre ; `.inc-cout-grid minmax(240px,1fr)` (globals.css:781) passe juste à 360 px, déborde < 320 px.
9. `components/IncendieAcces.js:90` : `.recap` `maxWidth: 420` inline OK ; bouton submit inline style correct (16px input). RAS majeur sur l'écran du code.
